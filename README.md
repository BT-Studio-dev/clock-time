# BT Clock (Clock Time) — v2.5.0

A modern, cinematic countdown application and world atomic clock featuring official downloadable editions for **Windows 10/11**, **Windows 7 (Legacy SP1+)**, and **Android 8.0+ (Oreo & Newer)**.

Live Web App: [https://clocktime-teal.vercel.app](https://clocktime-teal.vercel.app)

---

## ✨ Features in v2.5.0
- **Frosted Glassmorphism**: Full-page glassmorphism (`glass-deep`, `glass-pill`, and shimmering refractive borders).
- **Interactive Retro Pixel Engine**: Toggleable 8-bit retro pixel grid, floating square stars, and mouse-reactive particles.
- **Official Download Editions**:
  - **Windows 10 / 11**: Modern DirectX Fluent desktop installer & portable ZIP (`v2.4.0`)
  - **Windows 7**: Legacy SP1+ standalone compatibility installer & portable ZIP (`v1.8.6 LTS`)
  - **Android 8.0+**: Universal mobile APK package (`v2.3.1`)
- **Soundscapes & Ambience**: Integrated 10-track synthesized ambient library with real MP3 streaming and live Web Audio drone.
- **PWA & Offline Support**: Service worker caching, offline persistence, and installability with custom app icons.
- **In-App Version Updater**: Real-time update notifications and cache refresh banner.
